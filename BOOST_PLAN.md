## 6. Upwork: поведение ленты

- Вкладки «Лучшие» (топ по общей оценке, обычно 5–10) и «По сложности» (простая → тяжёлая; переключатель сортировки по совместимости в %).
- Сложность считается по признакам без модели (объём описания, число навыков, бюджет и срок, число вопросов клиента, расплывчатость).
- Совместимость % — составная, с разбором под числом: пересечение тегов (с весами) → подтверждение профилем и портфолио Upwork → база памяти ARIA (после H3) → оценка модели только для топ-N (экономит лимиты Gemini).
- Действия «скрыл / сохранил / откликнулся» подстраивают веса тегов.
- Накопительная база, не полная копия Upwork: теги из найденных вакансий + ручные + предложения соседних тегов по совстречаемости; срок хранения и потолок размера заданы.

## 7. Границы безопасности для Upwork

- Поиск, чтение, анализ, накопление базы — автоматически.
- Любой отклик: Approve в ARIA → подтверждение черновика на Upwork. Автоотправки нет.
- Перед Approve показываются цена в Connects и текущий баланс.
- Лимит подготовленных черновиков в день; расписание не запускает записывающие действия без ручного подтверждения.
- Тексты вакансий и сообщения клиентов — недоверенные данные.

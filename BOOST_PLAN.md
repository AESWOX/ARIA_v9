## 5. Upwork: факты (проверено 09.10 по upwork.com/ai/mcp и репозиторию плагина)

- Официальный сервер: `https://mcp.upwork.com/mcp`, streamable HTTP, OAuth 2.1 с динамической регистрацией клиента; локальной установки и API-ключей нет.
- Запись всегда черновиком с отдельным подтверждением; всё, что трогает деньги и офферы, завершается на upwork.com; пополнение Connects и платное продвижение — только на сайте (тул возвращает ссылку, в приложении кнопка «Открыть в браузере»). Доступ отзывается в Upwork: Account Settings → Connected Apps.
- Тулы фрилансера (из навыков плагина): `list_accounts` (первым вызовом, роль фрилансера `TALENT`), `find_jobs` с действиями `search` (по словам, весь маркетплейс), `smart_search` (под профиль; `best_match` / `most_recent`, фильтры по дате только для `most_recent`), `get` (детали: Connects, вопросы клиента, рейтинг клиента); `get_profile`, `list_highlights`, `connects_balance`, `list_freelancer_proposals`, `manage_proposals`; `search_tools`, `get_tool_help` (сервер самоописывающийся: имена и параметры брать из них, не угадывать).
- В строках поиска нет `connects_cost` (только в `get`); признак `applied` = уже откликались.
- Справочника всех навыков/тегов в известном списке тулов не видно; наличие проверить на живом.
- Неофициальные Upwork-MCP (npm, uv, браузерная автоматизация) не используем.
- Риск, снимается только на живом: redirect OAuth идёт на локальный адрес, порт установленной сборки случайный; принятие такого redirect сервером Upwork не проверено. Запасной вариант: фиксированный порт callback или deep-link Tauri.

## 6. Upwork: поведение ленты

- Вкладки «Лучшие» (топ по общей оценке, обычно 5–10) и «По сложности» (простая → тяжёлая; переключатель сортировки по совместимости в %).
- Сложность считается по признакам без модели (объём описания, число навыков, бюджет и срок, число вопросов клиента, расплывчатость).
- Совместимость % — составная, с разбором под числом: пересечение тегов (с весами) → подтверждение профилем и портфолио Upwork → база памяти ARIA (после H3) → оценка модели только для топ-N (экономит лимиты Gemini).
- Действия «скрыл / сохранил / откликнулся» подстраивают веса тегов.
- Накопительная база, не полная копия Upwork: теги из найденных вакансий + ручные + предложения соседних тегов по совстречаемости; срок хранения и потолок размера заданы.

## 7. Границы безопасности для Upwork

- Поиск, чтение, анализ, накопление базы — автоматически.
- Любой отклик: Approve в ARIA → подтверждение черновика на Upwork. Автоотправки нет.
- Перед Approve показываются цена в Connects и текущий баланс.
- Лимит подготовленных черновиков в день; расписание не запускает записывающие действия без ручного подтверждения.
- Тексты вакансий и сообщения клиентов — недоверенные данные.

# Security Policy

Об уязвимости сообщайте приватно: GitHub -> Security -> Report a vulnerability
(репозиторий AESWOX/ARIA_v9). Не открывайте публичный issue.
Укажите версию, шаги воспроизведения и влияние.

Ключи провайдеров хранятся локально и не должны попадать в репозиторий и логи.
Если ключ утёк - немедленно отзовите его у провайдера.
